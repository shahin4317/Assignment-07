# KeenKeeper

KeenKeeper is a relationship management web application where users can keep track of friends, communication history, and interaction timelines in one place. It helps users maintain meaningful connections through calls, texts, and video interaction tracking.

---

## 🚀 Technologies Used

- React
- React Router
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
- Recharts
- Vite

---

## ✨ Key Features

### 1. Friend Relationship Tracking
Users can view friend details, contact history, relationship goals, and overdue interactions.

### 2. Timeline Management
Track communication activities like calls, texts, and video chats with real-time timeline updates.

### 3. Interactive Statistics Dashboard
Beautiful charts and analytics using Recharts to visualize interaction types and relationship activity.
